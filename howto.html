遊び方

「1億2千万分の1」は、日本のどこかにランダムに生まれて、一度きりの人生を約10分で生きる無料のゲームです。登録や、課金なども不要です。スマホのブラウザでそのまま遊べます。

1. 生まれる

最初の画面で「生まれる」を押すと、生まれる県・性別・家の暮らし向き・生まれつきの体の強さが決まります。自分では選べません。県は実際の出生数の割合で決まるので、東京や神奈川に生まれる人が多く、鳥取や島根に生まれる人は少なくなります。

名前は入れても入れなくてもかまいません。空のままなら、その年に多かった名前からランダムに付きます。

2. 1年ずつ進む

「人生をはじめる」を押すと、0歳から1年ずつ時間が進みます。画面の上には4つの数字（健康・幸せ・学び・つながり）と、お金（貯金・投資・純資産）が出ます。下には、その年に起きたことが1行ずつ流れます。

  • ゆっくり／ふつう／はやい … 進む速さを変えられます。出来事の多い年は自動で少し長く止まります。
  • ⏸（一時停止） … 流れた文を読み返したいときに。
  • おまかせ … すべての決断を自動にします。眺めるだけで一生が終わります。

3. 決断する

一生のうちに30回ほど、選択肢が出て時間が止まります。部活・進路・仕事・結婚・家・子ども・健康診断・親の介護・定年・運転免許の返納など、多くの人が人生のどこかで迷うことです。選択肢は3つで、どの選択肢を選んでも、不正解はありません。選んだことが、数字やお金やその後の出来事に少しずつ響きます。

人生を大きく変えるのは、進路・仕事・結婚・家・定年の5つです。それ以外の決断は、本人が「自分で選べた」と感じるためのもので、結果への影響は小さめにしてあります。

4. 人生の終わり

毎年、その年齢の実際の死亡率に当たるかどうかで、人生が終わるかどうかが決まります。若いうちに終わる人生も、100歳を超える人生もあります。重い死因（自殺・事件）は統計どおりの割合で起こりますが、場面は描きません。最初の画面の「やさしい表示」をオンにすると、これらの死因は出なくなります。

5. 結果を残す

人生が終わると、結果の画面になります。

  • 結果カード … 県・享年・仕事・家族・生涯収入・最後の純資産などをまとめた1枚の画像。X や LINE に送ったり、端末に保存したりできます。
  • ショートムービー … 生まれてから最後までを約1分の縦動画にします。音楽つきです。「動画として保存」でスマホの共有シートに出せます。
  • 得意なこと・好きなこと … 体力・頭脳・芸術・社交・ものづくり・お金の6つの軸を図にします。部活・習い事・仕事・趣味などの選択で育ちます。
  • 人生地図 … 1マス1年、1行20年。色の濃さがその年の幸せの高さです。

6. もう一度、生まれる

「もう一度、生まれる」で、また別の人生がはじまります。遊んだ人生は「前世の記録」として、最初の画面に10件まで残ります。記録はこの端末のブラウザの中だけに保存され、どこにも送られません。

よくある質問

同じ県に生まれたいのですが、選べますか？
選べません。「生まれる場所は選べない」ことが、このゲームの土台です。
お金の数字は本物ですか？
年齢ごとの平均給与・生活費・住宅ローン・退職金・年金・相続などを、公開統計をもとにした概算で計算しています。詳しくは数字の根拠をご覧ください。
子ども向けですか？
15歳以上向けです。病気・死・借金・離婚など、人生の重い場面も統計どおりに起こります。
データはどこに送られますか？
ゲームの進行はすべてお使いの端末の中で計算し、名前や結果をサーバーへ送ることはありません。詳しくはプライバシーポリシーをご覧ください。
